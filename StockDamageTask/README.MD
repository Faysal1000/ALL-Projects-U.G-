\## Project Overview

This project involves developing the \*\*Stock Damage\*\* page using ASP.Net, HTML, Bootstrap, JQuery, and C#, with MS SQL Server as the database.



\### Key Features

\- Warehouse Name dropdown populated from \*\*Godown\*\* table

\- Item Name dropdown loaded from \*\*SubItemCode\*\* table, auto-populates Item Code and Unit

\- Stock display from \*\*Stock\*\* table

\- Default Batch No: "NA"

\- Currency dropdown with automatic exchange rate calculation

\- Input for Quantity, Rate, Amount In

\- Default Dr A/C Head: “Stock Damage”

\- Employee Name dropdown from \*\*Employee\*\* table

\- Comments input

\- Temporary Bootstrap table for multiple entries before saving

\- Save button stores all entries in \*\*Stock Damage\*\* table using stored procedure `SP\_TableName\_Save`



\### Technology Stack

\- \*\*Frontend \& Server-Side Logic:\*\* ASP.Net, C#  

\- \*\*Client-Side:\*\* HTML, Bootstrap, JQuery  

\- \*\*Database:\*\* MS SQL Server
